# Maiden tiedot

Full Stack Open -kurssin Maiden tiedot tehtävä.

Sovellus hakee maiden tiedot REST Countries -rajapinnasta ja mahdollistaa maiden hakemisen nimen perusteella.

## Toiminnallisuudet

- Maiden tietojen hakeminen ulkoisesta API:sta Axiosilla
- Maiden suodattaminen hakukentän avulla
- Liian suuren hakutulosmäärän käsittely
- Hakutulosten näyttäminen listana
- `show`-painike yksittäisen maan tietojen näyttämiseen
- Maan nimen, pääkaupungin ja pinta-alan näyttäminen
- Maan kielten näyttäminen
- Maan lipun näyttäminen

## Teknologiat

- React
- JavaScript
- Axios
- REST API
- Vite
